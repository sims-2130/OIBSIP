# Task 1: Iris Flower Classification

## Project Objective
To train a machine learning model capable of classifying iris flowers into their respective species.

## Tech Stack Used
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-learn
* **Environment:** Jupyter Notebook

## Key Architecture & Steps
1. **Exploratory Data Analysis (EDA):** Visualizing and understanding the dataset features.
2. **Feature Analysis:** Evaluating the target features and distributions.
3. **Model Selection & Evaluation:** Training classification algorithms to find the best fit.
